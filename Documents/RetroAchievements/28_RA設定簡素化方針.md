# RA設定簡素化方針

## 1. 決定

2026-07-19、他エミュレータに見られる複雑なRA設定を避けるため、初期版では独立した
RetroAchievements Settings画面を作らないことを決定した。

ユーザーが選択するRA設定は次の2つだけとする。

- `RA mode`: RA全体の有効／無効
- `Softcore／Hardcore`: Phase 8で既存RAメニューへ追加

最後に選択したSoftcore／Hardcoreは内部で記憶するが、`Last mode`という別の設定行は作らない。
Login／Logoutは設定ではなくアカウント操作として既存RAメニューに維持する。

## 2. 固定値と自動管理

- Unofficial achievements: OFF
- Encore mode: OFF
- Spectator mode: OFF
- 通知時間: 5秒
- 画像cache上限: 128MiB
- 破損画像: 読込時に自動削除して再取得
- cache容量超過: LRUで自動削除

Clear image cacheは通常UIへ出さない。Saved data managementもSettingsへ置かず、作業コピーに
対するユーザー操作が将来必要になった場合だけLibraryの媒体管理として設計する。

## 3. 互換性

既存`ra_settings` tableのUnofficial、Encore、Spectator、通知秒数、画像cache上限の列は削除しない。
既存DBとテストの互換性、および将来schemaを移行する余地を維持するためである。初期版Appは
これらの保存値をユーザー設定として読み込まず、上記の固定値を使用する。

## 4. 次の作業

独立Settings画面がPhase 6残件ではなくなったため、次はRA由来文字列を安全に変換・省略する
`RaTextRenderer`を実装し、Phase 6全体の完了監査を行う。その後、Phase 7のSoftcore専用stateへ
進む。
